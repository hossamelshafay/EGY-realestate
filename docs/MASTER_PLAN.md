## 1. Project Overview

**EGY DEVELOPMENT** is an AI-powered Egyptian real estate mobile application built with Flutter. The app connects homebuyers and renters with intelligent property search, AI-driven price predictions, personalized recommendations, and a conversational AI assistant — all backed by a fully-built Python/FastAPI backend.

### Vision

Deliver the most intelligent property search experience in Egypt by combining a beautiful, bilingual mobile UI with production-ready AI models that are already trained and serving.

## 6. Key Architectural Decisions

| Decision | Choice | Rationale |
|---|---|---|
| **Architecture** | MVVM + Feature-First | Clean separation, scalable, team-friendly |
| **State Management** | Cubit (flutter_bloc) | Simpler than full Bloc for most screens; testable |
| **Navigation** | go_router | Declarative, deep-link support, drawer-friendly |
| **DI** | get_it (+ injectable optional) | Simple service locator; injectable adds code-gen convenience |
| **Network** | dio | Interceptors, retry, logging out of the box |
| **Local Storage** | shared_preferences + hive | Preferences for settings, Hive for structured offline data |
| **Localization** | flutter_localizations + intl | Official solution with ARB files |
| **Font** | Cairo (Google Fonts) | Beautiful Arabic + Latin support |

## 10. Risks & Mitigations

| Risk | Severity | Mitigation |
|---|---|---|
| **Backend hosting not decided** | 🔴 High | FastAPI with ML models needs adequate compute (CPU/RAM). Recommend Cloud Run or Railway. Must decide before Phase 2. |
| **ML model size (~100MB+)** | 🟡 Medium | Models are server-side only; no impact on app size. But hosting must accommodate memory. |
| **LLM API costs (Gemini/Groq)** | 🟡 Medium | Implement rate limiting, caching frequent queries. Consider Groq free tier for development. |
| **Package name `com.example.egy`** | 🟡 Medium | Must rename before any store submission or Firebase Auth deep links. Do in Phase 0. |
| **No Git history** | 🟡 Medium | Initialize immediately in Phase 0. All work should be version-controlled. |
| **RTL complexity** | 🟡 Medium | Build RTL-aware from day one. Test Arabic layout on every screen. |
| **Firebase only partially configured** | 🟢 Low | FlutterFire CLI already run; just add `firebase_auth` and Firestore as needed. |
